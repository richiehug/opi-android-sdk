# 🎉 OPI Android SDK is out!

OPI Android SDK 1.0.0 brings OPI payment integration to Android POS and ECR applications. Connect to a separate network terminal while the SDK handles TCP communication, XML messages, terminal callbacks, and transaction results.

## Highlights in 1.0.0

- Kotlin API with an explicit terminal address and two-channel OPI TCP communication.
- Payments, refunds, reversals, and terminal operations.
- Typed transaction results, receipts, and DCC information.
- Status events, explicit abort, and ECR-controlled reconciliation.
- Network-loss detection and operation wake locks for reliable operation lifecycle handling.
- Optional SDK diagnostics with normal and extended log levels; logging is off by default.
- Your application owns the payment screen and transaction experience. The SDK contains no overlay or branding components.
