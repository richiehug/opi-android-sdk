OpiAndroidSdk

class OpiAndroidSdk

Integrates OPI-compatible payment terminals with an Android merchant application.

The SDK connects the application to an OPI endpoint over a network connection to a separate terminal and provides typed financial operations, terminal administration, receipts, DCC results and recovery. Create one instance with create and retain it for the lifetime of the integration.

All terminal-facing methods are suspending and return operational outcomes as OpiResult. Regular operations are serialized. abort is the only out-of-band operation and applies only while a payment or refund is active.
