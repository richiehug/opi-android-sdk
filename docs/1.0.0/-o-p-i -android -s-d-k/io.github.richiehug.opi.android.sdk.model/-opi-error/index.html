OpiError

enum OpiError : Enum<OpiError>

Stable SDK-facing classification derived from detailed OPI and transport error codes.

Inspect OpiResult.status first, then this value. In particular, RESULT_UNKNOWN means the request may have completed and must not be resent blindly.
