TerminalInformation

data class TerminalInformation(val terminalId: String? = null, val terminalIp: String? = null, val appVersion: String? = null, val merchantId: String? = null, val status: String? = null, val subStatus: String? = null, val hardware: String? = null, val serialNumber: String? = null, val configurationName: String? = null, val configurationVersion: String? = null, val supportedBrands: List<String> = emptyList(), val initialisedAcquirers: List<String> = emptyList())

Terminal identity, application, status, configuration, brand, and acquirer information.

Fields are nullable because availability varies between Info, Status, and terminal firmware. Brand and acquirer collections are always present and default to empty.
